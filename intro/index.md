# 量潮搜索工程路线图

## 当前优先

原型已跑通，当前的工作重心是度量。度量的推进方式是先跑后立：以现有数据与原型取得第一眼结果，结论可判定之后，再定死指标、构建考题集、跑对照实验。评测不是算法之后的一道手续，而是本阶段的主要工程；正式投入的时机由第一眼结果决定。

去处：评测怎么判断见洞察仓[搜索好不好用怎么判断](../../insight/evaluation/index.md)，实验设计与队列见实验室 [evaluation-plan](../../../examples/quanttide-search-lab/docs/evaluation-plan.md)，先做什么、为什么这个顺序见[排法](ordering.md)。远景（为什么做、做成什么样、哪些不做）在意图仓；本仓维护规范见 [CONTRIBUTING](CONTRIBUTING.md)。
